## 2. 이번에 구현하는 기능 (병목 직결 순)

### F1. 회차 페이지 "회차 분석" 섹션 (build_pages.py) — AdSense 독창성
`render_session_page` 헤더 직후에 회차별 실데이터 기반 고유 블록 추가:
- 과목별 문항 구성 (문항 수)
- 이 회차 빈출 개념 top 10 (`concepts[]` 빈도, 2회 이상만)
- 실수치 요약 문단 (과목 수·개념 등장 횟수 — 페이지마다 실제로 다른 텍스트)
- 이전/다음 회차 내부 링크 (SEO 내부링크 + 탐색)

의도: "동일 템플릿 scaled content" 판정 완화. 회차마다 데이터가 달라 텍스트가 실제로 고유해짐. SPA 하이드레이션 시 세션 페이지 prerender는 기존 동작 유지(문항은 SPA가 대체 렌더).

### F2. 학습 스트릭 (app.js) — 리텐션(재방문 → 광고 노출 기반)
- 저장: `examkr.v1.activity` = `{ days: { 'YYYY-MM-DD': 문항수 } }`. 답변 기록 지점(choice 선택)에서 +1. 최근 70일만 유지.
- 계산: 오늘(또는 어제)부터 역산 연속일 + 최고 기록.
- 노출: ① 홈 타이틀 아래 스트릭 칩(활동 있을 때만), ② 통계 화면에 스트릭 + 최근 7일 미니바.
- export/import 화이트리스트(`sanitizeImportEntry`)에 `activity` 추가.

### F3. 모의시험 결과 공유 (app.js) — 바이럴 획득
- 기존 완료 시트의 "공유" 버튼이 점수 없는 일반 링크 공유 → 모의시험 결과일 때 `"{자격증} {날짜} 모의시험 {pct}점 ({correct}/{total})"` 텍스트 + `?utm_source=share&utm_medium=social&utm_campaign=result_share` 링크로 강화 (MARKETING.md UTM 스키마 준수).
- 수험 커뮤니티 점수 인증 문화와 시너지 — 공유 유입을 Vercel Analytics 에서 측정 가능.

### 반영 규칙
- app.js 수정 → `index.html ?v=29`, `sw.js VERSION v31`.
- 기존 미커밋 변경(데이터 품질 작업·파이프라인 개선, 이전 세션 잔여물)은 건드리지 않고 분리 커밋.

## 3. 수익화 로드맵 (구현 아닌 순서 합의)

1. **지금 (사용자 액션 대기)**: 쿠팡 파트너스 가입 → affiliate.json 채우기 (심사 없음, 관련성·단가 최고). AdFit 가입 → unit 설정. 토스 익명 후원 링크 → DONATE.
2. **AdSense 재심사**: F1 배포 + 재크롤 후 신청. 또 거절되면 남은 카드는 AI 해설 템플릿 다변화(회차·과목별 해설 구조 변주 — 파이프라인 재실행 비용 큼).
3. **트래픽 부트스트랩**: MARKETING.md 플레이북 (AdSense 통과가 게이트). 정보처리기사 8월 말 시험 = 다음 골든 윈도우.
4. **구독(프리미엄) 착수 조건**: DAU 300~500+ 지속 시. 후보 프리미엄 기능: 광고 제거, 오답 기반 맞춤 모의고사(전 회차 크로스), 학습 플래너(D-day 기반), 기기간 동기화(KV 계정). 결제 경로: 1단계 토스 익명후원(리워드 없음) → 2단계 라이선스 키 판매(Gumroad, 사업자 불필요, api/license.js + KV 검증) → 3단계 토스페이먼츠 정기결제(사업자 등록 필요).
5. **구독 전 준비물(개발 관점)**: 기기간 식별(익명 계정 or 키), 광고 제거 플래그, 프리미엄 게이트 — 전부 1~2일 작업이라 임계치 도달 후 해도 늦지 않음. 지금 만들면 죽은 코드.

## 4. 검증 계획

- F1: `python3 scripts/build_pages.py` 성공 + 산출 HTML에 회차 분석 섹션·prev/next 링크 확인 (2개 이상 회차 샘플 diff — 실제로 서로 다른 텍스트인지).
- F2: 스트릭 계산 순수함수를 node 로 케이스 검증 (연속/단절/오늘 미풀이/빈 데이터).
- F3: 코드 경로 확인 (exam 모드 completion → 점수 텍스트 + UTM url).
- 전체: 빌드 후 dist 홈/개요/세션 광고 게이트 불변 확인.
