# 과목 넘기기 바 (Subject Navigation Bar) — 설계

- 날짜: 2026-07-02
- 대상: `webapp/app.js`, `webapp/app.css` (순수 HTML/JS SPA, 빌드/테스트 프레임워크 없음)
- 상태: 승인됨

## 배경 / 문제

퀴즈 화면은 문항을 좌우 스와이프(가로 페이지) 방식으로 이동한다. 과목 단위 이동은 이미
존재하지만(`openJumpSheet` 의 과목 칩) **"바로가기 시트" 안에 묻혀 있어** 발견성이 낮다.
사용자는 풀이 중 **현재 과목을 건너뛰고 다른 과목으로 바로 이동**하길 원한다.

## 목표

퀴즈 화면에 **항상 보이는 전용 바**를 두어 과목 간 이동(이전/다음)을 1탭으로 제공한다.

## UI / 배치

퀴즈 헤더(`#quizNav`)와 진도바(`.progress`) 사이에 슬림 바 삽입:

```
‹ 이전 과목      3과목 · 사회통계      다음 과목 ›
```

- 왼쪽: `‹ 이전 과목` 버튼, 가운데: 현재 과목 라벨, 오른쪽: `다음 과목 ›` 버튼.
- 항상 보임 → 발견성 문제 해결.
- 컨셉 배너(`renderConceptBanner`)와 위치 충돌하지 않도록 헤더 바로 아래, 배너 위/아래 배치는 구현 시 확정(기본: 헤더 → 과목바 → 배너 → 진도바).

## 동작

- `다음 과목 ›` → 다음 과목의 **첫 문제**로 이동. `‹ 이전 과목` → 이전 과목의 첫 문제로.
- 이동은 기존 메커니즘 재사용: `pages.scrollTo({ left: firstIdx * pages.clientWidth, behavior: 'smooth' })`.
- 현재 문제가 바뀔 때마다(스와이프/점프시트/페이지nav) 바의 **가운데 라벨 + 좌우 버튼 활성상태**를 갱신.
  기존 문항변경 훅(현재 `#quizSub.textContent = q.subject` 세팅 지점, app.js:2534 부근)에 연결.

## 데이터 / 로직

- `data.questions` 를 순서대로 순회해 과목 그룹 계산: `[{ subject, firstIdx }]` (첫 등장 순서).
  기존 데이터는 "N과목 : 과목명" 연속 블록이라 그대로 그룹핑됨.
- 현재 과목 = 현재 문항 index 가 속한 그룹. 이전/다음 = 인접 그룹.
- 라벨 파싱: `"1과목 : 사회통계"` → `"1과목 · 사회통계"` (콜론→가운뎃점, trim). 파싱 실패 시 원문 그대로.

## 엣지 케이스

- 첫 과목: `‹ 이전 과목` 비활성(dim, 클릭 불가). 마지막 과목: `다음 과목 ›` 비활성.
- **과목이 1개거나 subject 값이 없음 → 바 전체 숨김.** (단일과목 시험 등)
- 오답노트·개념연습 등 필터/가상 세션: 과목 종류 > 1 일 때만 표시. 이동은 "해당 과목 첫 등장 index" 기준(비연속이어도 안전).

## 모드 영향

순수 네비게이션 — 채점·진도·localStorage 에 영향 없음. 풀이/시험/오답 모드 공통.
시험 모드에서도 "이동"만이며 답안 스킵이 아님.

## 구현 범위 (surgical)

- `webapp/app.js`:
  - `openQuiz` 템플릿에 `.subject-bar` markup 추가.
  - 과목 그룹 계산 헬퍼 (`openJumpSheet` 의 subject 파싱 로직 재사용/공유).
  - 이전/다음 핸들러 (기존 scrollTo 재사용).
  - 문항변경 시 바 갱신 함수 (라벨 + 버튼 disabled 토글). 단일과목이면 바 hidden.
- `webapp/app.css`: `.subject-bar` 슬림 스타일 (테마 토큰 사용, 비활성 dim).
- asset 버전 bump (app.js / app.css / sw).

## 비목표 (YAGNI)

- 과목별 진도/정답률 표시 (별도 기능).
- 과목 순서 커스터마이즈.
- 기존 `openJumpSheet` 과목 칩 제거 (유지 — 임의 과목 점프는 시트가 담당).

## 검증 (수동)

이 앱은 빌드/유닛테스트 프레임워크가 없으므로 브라우저 수동 검증:

1. 다과목 시험(iz 5과목) 열기 → 바 표시, 라벨/버튼상태 정확.
2. `다음 과목 ›`·`‹ 이전 과목` 이동이 각 과목 첫 문제로 정확히 감.
3. 스와이프로 과목 경계를 넘을 때 가운데 라벨·버튼상태 자동 갱신.
4. 첫 과목에서 이전 비활성, 마지막 과목에서 다음 비활성.
5. 단일과목/과목없음 세션 → 바 숨김.
6. 라이트/다크 테마에서 스타일 정상.
